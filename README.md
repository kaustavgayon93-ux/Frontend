# Ashtalakshmi MRV Frontend

Frontend for the Ashtalakshmi MRV (Measurement, Reporting, and Verification) platform for forest monitoring and carbon assessment.

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

## Backend Requirement
The frontend expects a FastAPI backend running at `http://localhost:8000`.

## Features
- Dashboard with key metrics and quick actions
- Project Management
- Field Data Collection (PWA ready)
- Satellite Imagery Ingestion
- Carbon Assessments
- Audit Trail

## Tech Stack
- Next.js 15
- React 19
- Tailwind CSS
- MapLibre GL JS + react-map-gl
- Recharts
- Lucide React
- TypeScript
